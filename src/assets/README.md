# Directorio de Assets

Este directorio contiene todos los recursos estáticos del portafolio:

## 📁 Estructura recomendada:
- `images/` - Imágenes del portafolio
  - `profile.jpg` - Tu foto de perfil
  - `projects/` - Imágenes de proyectos
- `documents/` - Documentos descargables
  - `cv.pdf` - Tu curriculum vitae
- `icons/` - Iconos personalizados (si los tienes)

## 📝 Notas:
- Las imágenes deben ser optimizadas para web
- Formato recomendado: JPG para fotos, PNG para imágenes con transparencia
- Tamaño máximo recomendado: 500KB por imagen
